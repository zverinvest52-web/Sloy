"""
Настройка параметров для наклонных линий

## Текущие параметры HoughLinesP:

```python
self.hough_threshold = 50        # Минимум голосов для линии
self.hough_min_line_length = 50  # Минимальная длина линии (px)
self.hough_max_line_gap = 10     # Максимальный разрыв между сегментами
```

## Проблема с наклонными линиями:

HoughLinesP может фрагментировать наклонные линии на множество сегментов,
особенно если линия имеет неровности или разрывы.

## Решения:

### Вариант 1: Увеличить hough_max_line_gap (быстро)
```python
self.hough_max_line_gap = 20  # было 10
```
**Эффект**: Объединяет сегменты с большими разрывами
**Риск**: Может объединить несвязанные линии

### Вариант 2: Уменьшить hough_min_line_length (для коротких сегментов)
```python
self.hough_min_line_length = 30  # было 50
```
**Эффект**: Находит более короткие линии
**Риск**: Больше шума

### Вариант 3: Настроить merge_collinear_segments (рекомендуется)
```python
# В _merge_lines():
angle_tolerance_deg = 10.0  # было 5.0 - больше толерантность к углу
distance_tolerance = 20.0   # было 10.0 - больше расстояние для объединения
```
**Эффект**: Лучше объединяет наклонные фрагменты
**Риск**: Минимальный

### Вариант 4: Адаптивные параметры по углу линии
```python
def adaptive_merge_tolerance(angle):
    # Для наклонных линий (30-60°) используем большую толерантность
    if 30 <= abs(angle) <= 60:
        return 15.0  # градусов
    else:
        return 5.0   # для горизонтальных/вертикальных
```

## Рекомендация:

Начните с Варианта 3 - увеличьте толерантности в merge_collinear_segments:
- angle_tolerance_deg: 5° → 10°
- distance_tolerance: 10 → 20

Это безопасно и эффективно для наклонных линий.

## Тестирование:

Создайте чертёж с:
- Вертикальной линией (0°)
- Горизонтальной линией (90°)
- Наклонной линией (45°)
- Наклонной линией (30°)

Все должны быть цельными, не фрагментированными.
