Улучшения детекции окружностей - исправление потери малых и больших отверстий

## Проблемы, которые были:
1. Малые окружности (радиус < 10px) игнорировались
2. Большие отверстия (радиус > 200px) игнорировались
3. Окружности близко к контурам терялись
4. Использовался только ОДИН метод детекции (contour ИЛИ Hough)
5. Возвращалась только ОДНА окружность (самая маленькая)

## Что исправлено:

### 1. Расширен диапазон радиусов
```python
self.circle_min_radius = 3   # было 10 → теперь 3
self.circle_max_radius = 500 # было 200 → теперь 500
```

### 2. Используются ОБА метода детекции
```python
def _extract_circles(self, image):
    circles_contour = self._extract_circles_contour(image)
    circles_hough = self._extract_circles_hough(image)

    # Объединяем результаты, удаляя дубликаты
    all_circles = circles_contour + circles_hough
    return deduplicate(all_circles)
```

**Почему это важно:**
- Contour method: хорош для чистых окружностей
- Hough method: находит окружности с толстыми линиями
- Вместе: находят больше окружностей

### 3. Возвращаются ВСЕ найденные окружности
```python
# Было:
return circles[:1]  # только первая

# Стало:
return circles  # все найденные
```

### 4. Поиск на двух изображениях
```python
# Ищем на residual (без контуров)
circles_residual = self._extract_circles(residual)

# Ищем на полном изображении
circles_full = self._extract_circles(working_image)

# Объединяем результаты
circles = merge_and_deduplicate(circles_residual, circles_full)
```

**Почему это важно:**
- Residual: находит окружности внутри контуров
- Full image: находит окружности близко к контурам
- Вместе: не теряем окружности в любом положении

## Ожидаемые улучшения:

✅ **Большие отверстия (200-500px)**: теперь детектируются
✅ **Окружности у контуров**: находятся на full image
✅ **Множественные окружности**: все сохраняются, не только одна

## Наклонные линии:

Для наклонных линий текущая система работает, но может фрагментировать их.
Алгоритм merge_collinear_segments() должен их объединять.

Если проблема остаётся, можно:
1. Увеличить hough_max_line_gap (сейчас 10)
2. Уменьшить hough_min_line_length (сейчас 50)
3. Настроить angle_tolerance в merge (сейчас 5°)
